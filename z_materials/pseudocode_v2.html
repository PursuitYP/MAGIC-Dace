Diversity-Driven LLM Safety Co-Evolution

基于多样性驱动的 LLM 安全攻防协同演化框架 — 伪代码

定义 1：攻击策略空间

二维攻击策略空间 $\mathcal{B} = \mathcal{S} \times \mathcal{C}$，$\mathcal{S}$ = 风险类别（$|\mathcal{S}|$ 类），$\mathcal{C}$ = 攻击方式（$|\mathcal{C}|$ 种）。每个攻击样本 $x$ 映射到 $b(x) = (s,c) \in \mathcal{B}$。

  • Archive $\mathcal{A}$：记录所有成功攻击样本的策略槽位频次 $n(b)$
  • 分布 $\mathbf{p}_{\mathcal{A}}$：各槽位归一化频率，$p_b = n(b) / \sum_{b'} n(b')$

定义 2：归一化边际覆盖增益（多样性奖励）

$R_{\text{div}}(x) = \dfrac{H(\mathbf{p}_{\mathcal{A} \cup \{x\}}) - H(\mathbf{p}_{\mathcal{A}})}{\max_{b \in \mathcal{B}} \bigl[H(\mathbf{p}_{\mathcal{A} \cup \{x_b\}}) - H(\mathbf{p}_{\mathcal{A}})\bigr] + \epsilon}$
  • 分子 = 样本 $x$ 的实际边际熵增；分母 = 当前 Archive 下单步最优边际增益（batch 内共享）
  • 两者均为 $O(1/|\mathcal{A}|)$，比值恒为 $O(1)$，消除 reward vanishing
  • 落入低频槽位 → 高奖励（≈1）；落入饱和槽位 → 低/负奖励

定义 3：贝叶斯对抗回放池

回放池 $\mathcal{R}$ 存储攻击成功的改写 prompt（不含防御者回复）。每个样本 $x_i$ 维护：

$p_i \mid s_i, f_i \;\sim\; \text{Beta}(\alpha + s_i,\; \beta + f_i)$
  • 入池：Stage 1 & Stage 2 中攻击成功（harmful response）的样本连同 $b(x)$ 入池
  • 更新：Stage 3 回放时，攻破 → $s_i\!+\!=\!1$；被拒 → $f_i\!+\!=\!1$
  • 时间衰减：每轮开始 $s_i \leftarrow \gamma s_i$，$f_i \leftarrow \gamma f_i$（$\gamma \in [0.95,0.99]$）
  • 采样：Thompson Sampling，$\tilde{p}_i \sim \text{Beta}(\alpha\!+\!s_i, \beta\!+\!f_i)$，取 top-$k$
  • 剪枝：$\hat{p}_i < \epsilon$ 且 $(s_i\!+\!f_i) > n_{\min}$ 时移除
Algorithm 1  多样性驱动的 LLM 安全攻防协同演化（三阶段，Attacker 先手）
Require: 攻击者 $\pi_A$，防御者 $\pi_D$，种子数据集 $\mathcal{D}_{\text{RL}}$，攻击策略空间 $\mathcal{B} = \mathcal{S} \times \mathcal{C}$，
    Archive $\mathcal{A} \leftarrow \emptyset$，回放池 $\mathcal{R} \leftarrow \emptyset$，Safety Judge $J$，轮数 $K$，组大小 $G$
Phase 1: Initialization
1$\pi_A \leftarrow \text{SFT}(\pi_A, \mathcal{D}_{\text{sft}})$ // 攻击者 SFT 热启动
2$\pi_D \leftarrow$ Base Model
Phase 2: Co-evolution
3for round $k = 1$ to $K$ do
4$\mathcal{D}_{\text{success}} \leftarrow \emptyset$ // 本轮收集的攻击成功样本
Stage 1 攻击者训练（固定 $\pi_D$）
5for $t = 1$ to $T_A$ do
6采样种子 batch $\{q_i\} \sim \mathcal{D}_{\text{RL}}$
7for each seed $q_i$ do
8攻击者生成 $G$ 个 rollout：$\{x_i^{(g)}\}_{g=1}^G \sim \pi_A(\cdot \mid q_i,\, \mathcal{B})$
// 攻击者推理选择策略 $(s,c)$ 并改写 prompt
9防御者生成单条响应：$y_i^{(g)} \sim \pi_D(\cdot \mid x_i^{(g)})$
10评估行为描述符：$b(x_i^{(g)}) \leftarrow J(x_i^{(g)})$
11判定攻击成败：$\text{succ}_i^{(g)} \leftarrow J(y_i^{(g)}) = \texttt{harmful}$
// ── 攻击者奖励（直接相加，无 GDPO）──
12$r_{\text{eff}} \leftarrow \text{Effectiveness}(x_i^{(g)}, y_i^{(g)})$ // harmfulness + consistency
13$\Delta_{\max} \leftarrow \max_{b \in \mathcal{B}}[H(\mathbf{p}_{\mathcal{A} \cup \{x_b\}}) - H(\mathbf{p}_{\mathcal{A}})]$ // 单步最优熵增（batch 共享）
14$r_{\text{div}} \leftarrow [H(\mathbf{p}_{\mathcal{A} \cup \{x_i^{(g)}\}}) - H(\mathbf{p}_{\mathcal{A}})] \;/\; (\Delta_{\max} + \epsilon)$
15$\lambda \leftarrow$ if $\text{succ}$ then $1.0$ else $0.5$ // 差异化多样性系数
16$R_A^{(g)} \leftarrow r_{\text{eff}} + \lambda \cdot r_{\text{div}}$ // 直接相加
17if $\text{succ}_i^{(g)}$ then $\mathcal{A} \leftarrow \mathcal{A} \cup \{x_i^{(g)}\}$; $\;\mathcal{D}_{\text{success}} \leftarrow \mathcal{D}_{\text{success}} \cup \{x_i^{(g)}\}$
// 成功样本更新 Archive 并暂存
18$\pi_A \leftarrow$ GRPO-Update$(\pi_A,\; \{R_A^{(g)}\})$ // 标准 GRPO group advantage
Stage 2 防御者训练（固定 $\pi_A$，当前轮新攻击）
19for $t = 1$ to $T_D$ do
20采样种子 batch $\{q_i\} \sim \mathcal{D}_{\text{RL}}$
21for each seed $q_i$ do
22攻击者生成单条攻击：$x_i \sim \pi_A(\cdot \mid q_i,\, \mathcal{B})$
23防御者生成 $G$ 个 rollout：$\{y_i^{(g)}\}_{g=1}^G \sim \pi_D(\cdot \mid x_i)$
24$R_D^{(g)} \leftarrow \text{DefReward}(x_i, y_i^{(g)})$ // safety + helpfulness − over-refusal
// ── 收集本阶段攻击成功样本 ──
25if $\exists\, g:\; J(y_i^{(g)}) = \texttt{harmful}$ then
26 $\mathcal{A} \leftarrow \mathcal{A} \cup \{x_i\}$; $\;\mathcal{D}_{\text{success}} \leftarrow \mathcal{D}_{\text{success}} \cup \{x_i\}$
27$\pi_D \leftarrow$ GRPO-Update$(\pi_D,\; \{R_D^{(g)}\})$ // 防御者学习应对最新攻击
// ── 将 Stage 1 & 2 收集的成功样本统一入池 ──
28for each $x \in \mathcal{D}_{\text{success}}$ do
29if $x \notin \mathcal{R}$ then $\mathcal{R} \leftarrow \mathcal{R} \cup \{(x,\, b(x),\, s\!=\!1,\, f\!=\!0)\}$ // 新样本
30else $s_x \leftarrow s_x + 1$ // 已存在则累加成功计数
Stage 3 回放池防御者训练（历史高风险攻击回放）
31for each $x_i \in \mathcal{R}$ do $s_i \leftarrow \gamma\, s_i$，$f_i \leftarrow \gamma\, f_i$ // 时间衰减
32for each $x_i \in \mathcal{R}$ do $\tilde{p}_i \sim \text{Beta}(\alpha + s_i,\, \beta + f_i)$ // Thompson Sampling
33$\mathcal{D}_{\text{replay}} \leftarrow \text{Top-}k\bigl(\{\tilde{p}_i\}\bigr)$ // 采样值最高的 $k$ 个样本
34for each $x \in \mathcal{D}_{\text{replay}}$ do
35防御者生成 $G$ 个 rollout：$\{y^{(g)}\}_{g=1}^G \sim \pi_D(\cdot \mid x)$
36$R_D^{(g)} \leftarrow \text{DefReward}(x, y^{(g)})$
// ── 贝叶斯后验更新 ──
37if $J(y^{\text{best}}) = \texttt{harmful}$ then $s_x \leftarrow s_x + 1$ // 仍被攻破
38else $f_x \leftarrow f_x + 1$ // 已防住
39$\pi_D \leftarrow$ GRPO-Update$(\pi_D,\; \mathcal{D}_{\text{replay}},\; \{R_D^{(g)}\})$ // 防御者巩固历史防御
// ── 回放池剪枝 ──
40for each $x_i \in \mathcal{R}$: if $\hat{p}_i < \epsilon$ and $(s_i\!+\!f_i) > n_{\min}$ then $\mathcal{R} \leftarrow \mathcal{R} \setminus \{x_i\}$
41Return $\pi_A,\; \pi_D$
与 MAGIC 的关键差异：
① 训练顺序：MAGIC 为 Defender → Attacker（防御者先手），本方法改为 Attacker → Defender（攻击者先手）。
② 攻击多样性：新增显式二维策略空间 $\mathcal{B} = \mathcal{S} \times \mathcal{C}$ 引导 + 归一化边际覆盖增益作为多样性奖励，与有效性奖励直接相加。
③ 三阶段训练：Stage 1（攻击者 RL）和 Stage 2（防御者 RL）均收集攻击成功样本入池；Stage 3 从贝叶斯回放池 Thompson Sampling 采样历史攻击单独训练防御者，解耦"适应新攻击"与"巩固旧防御"。
④ 回放池机制：入池样本仅为攻击者改写后的 prompt（不含防御者回复），采用 Beta-Bernoulli 后验追踪有效性 + 时间衰减适应防御者漂移。
