# 基于多样性驱动的 LLM 安全攻防协同演化框架

---

## 一、攻防协同演化总览

> 研究动机：现有攻防协同框架中，攻击者在 RL 训练中倾向于过拟合到少数高回报模式（策略坍缩），同时防御者在学习应对新攻击时会逐渐遗忘对旧攻击的防御能力（对抗遗忘）。本研究的核心目标是从策略层面系统性地提升攻击多样性，并通过历史对抗经验的有效管理缓解防御遗忘。
技术路线包含三个环节：第一，定义结构化攻击策略空间（风险类别×攻击方式），在攻击者输入中显式提供完整策略空间描述，攻击者先推理选择最合适的策略再改写 prompt，将多样性探索从隐式语义约束提升为显式策略选择。第二，设计双信号多样性奖励：边际覆盖增益度量样本对全局策略分布熵的边际贡献，提供宏观探索导航；频率逆向新颖性基于历史频次反比惩罚，提供远离热门区域的微观约束。成功样本获完整多样性激励，失败样本获折减激励，确保有效性优先的同时为冷门策略保留探索梯度。采用 GDPO 逐奖励解耦归一化，对各奖励分量在 group 内独立标准化后加权聚合，解决覆盖度信号被有效性奖励淹没的问题。第三，构建贝叶斯对抗回放池存储历史高风险攻击，为每个样本维护 Beta-Bernoulli 后验追踪其对当前防御者的有效性，配合时间衰减适应防御者能力漂移，通过 Thompson Sampling 实现探索-利用平衡的采样，在防御者训练时混入高风险历史攻击以缓解对抗遗忘。

本框架将 LLM 安全训练建模为攻击者（Attacker）与防御者（Defender）之间的动态对抗博弈。攻防双方各自持有独立模型参数，通过强化学习从对抗交互中提取奖励信号并迭代更新策略。核心设计目标有三：（1）攻击者在显式策略引导和多样性奖励下持续拓展攻击策略空间覆盖；（2）防御者在当前攻击与历史高风险攻击的混合训练下同步提升鲁棒性；（3）对抗回放池动态淘汰过时样本并吸纳新的高风险样本，三者构成闭环演化系统。

整体训练流程按以下步骤迭代：

**步骤 1：攻击者策略推理与改写。** 从种子 prompt 数据集中采样初始 prompt，同时向攻击者提供完整的策略空间描述（如 \(|\mathcal{S}|\) 种风险类别 \(\times\) \(|\mathcal{C}|\) 种攻击方式）。攻击者首先推理选择一种最适合当前 prompt 的攻击策略 \((s, c)\) 作为隐式动作，然后在该策略的引导下将初始 prompt 改写为具有隐蔽性的对抗 prompt。

**步骤 2：攻防交互与多维评估。** 改写后的 prompt 提交给当前版本的防御者生成响应。由安全评估模型（如 Llama Guard）和 LLM Judge 对以下维度进行评估：攻击 prompt 的有害性、防御者响应的有害性与拒答情况、攻击样本的行为描述符 \(b(x) = (s, c)\)。

**步骤 3：攻击者奖励计算与更新。** 根据攻击有效性（harmfulness + consistency）和攻击多样性（coverage + novelty）计算攻击者的复合奖励，通过 GRPO 更新攻击者策略。攻击成功的样本加入对抗回放池。

**步骤 4：防御者训练数据构建与更新。** 防御者的训练数据由当前轮次的新攻击 prompt 和从对抗回放池中通过 Thompson Sampling 采样的历史高风险 prompt 混合组成。根据安全拒答率、任务完成度、过拒惩罚计算防御者奖励，通过 GRPO 更新防御者策略。同时根据防御者对回放池样本的响应结果，按贝叶斯后验规则更新回放池中各样本的有害性估计。

**步骤 5：迭代演化。** 重复步骤 1–4。攻击者在多样性奖励驱动下持续拓展策略空间，防御者在混合训练数据下同步提升，回放池动态进化，形成闭环。

## 二、显式攻击策略引导与多样性奖励

### 2.1 攻击策略空间定义

我们定义攻击策略空间 \(\mathcal{B} = \mathcal{S} \times \mathcal{C}\)，其中 \(\mathcal{S}\) 为风险类别集合（如暴力犯罪、非暴力犯罪、性相关犯罪、自残自杀、仇恨歧视、危险物质与武器等），\(\mathcal{C}\) 为攻击方式集合（如角色扮演、权威操纵、术语伪装、故事嵌入、逻辑诱导等）。每个攻击样本 \(x\) 被映射到策略空间中的一个行为描述符 \(b(x) = (s, c) \in \mathcal{B}\)。

在攻击者的输入 prompt 中，我们直接提供完整的策略空间描述（所有 \(|\mathcal{S}| \times |\mathcal{C}|\) 种策略组合的定义和示例）。攻击者需要：（1）根据原始 prompt 的内容推理选择一种最合适的攻击策略；（2）在所选策略的引导下将原始 prompt 改写为具有隐蔽性的有害 prompt。行为描述符的评估由安全分类模型（风险类别 \(s\)）和 LLM Judge（攻击方式 \(c\)）分别判定。

### 2.2 攻击者奖励结构

攻击者的总奖励由攻击有效性奖励和攻击多样性奖励两部分组成。多样性奖励对攻击成功与失败的样本施加不同的激励强度——成功样本获得完整的多样性奖励，失败样本获得折减的多样性奖励，确保多样性探索优先服务于攻击有效性，同时不完全放弃对失败样本的策略分散引导：

\[
R_{\text{attack}}(x) = R_{\text{effective}}(x) + \lambda(x) \cdot R_{\text{diversity}}(x)
\]

其中多样性激励系数 \(\lambda(x)\) 根据攻击成败进行差异化设置：

\[
\lambda(x) = \begin{cases} 1.0 & \text{if attack\_success}(x) \\ 0.5 & \text{otherwise} \end{cases}
\]

多样性奖励由策略空间覆盖度和当前策略新颖性构成：

\[
R_{\text{diversity}}(x) = \alpha \cdot R_{\text{coverage}}(x) + \beta \cdot R_{\text{novelty}}(x)
\]

**差异化激励的设计动机：**

- **攻击成功样本（\(\lambda = 1.0\)）：** 这些样本已验证对防御者具有实际威胁，其策略选择具有安全评估价值。给予完整的多样性奖励，最大化激励攻击者在有效攻击的前提下拓展策略覆盖。
- **攻击失败样本（\(\lambda = 0.5\)）：** 此前的设计将失败样本的多样性奖励完全屏蔽（\(\lambda = 0\)），但这会导致一个问题：如果某个冷门策略在当前阶段尚未学会有效攻击，其探索信号会完全消失，攻击者将迅速放弃对该策略方向的尝试。保留折减的多样性奖励（\(\lambda = 0.5\)）可以在不过度激励无效攻击的前提下，为冷门策略方向维持基本的探索压力，给予攻击者继续尝试和改进的梯度信号。
- **有效性优先原则：** \(\lambda_{\text{success}} = 2 \times \lambda_{\text{fail}}\) 的比例确保，在 GRPO 的 group 内 advantage 计算中，攻击成功且策略新颖的样本相比攻击失败但策略新颖的样本获得显著更高的综合 advantage，从而在梯度更新中优先强化"既有效又多样"的攻击行为。


### 2.3 策略空间覆盖度：归一化边际覆盖增益（Normalized Marginal Coverage Gain）

覆盖度奖励衡量攻击策略对行为空间 \(\mathcal{B}\) 的整体覆盖与均衡程度。

**原始定义及其局限。** 基础的边际覆盖增益直接度量单个样本对全局策略分布熵的边际贡献：

\[
R_{\text{coverage}}^{\text{raw}}(x) = H(\mathbf{p}_{\mathcal{A} \cup \{x\}}) - H(\mathbf{p}_{\mathcal{A}})
\]

其中 \(\mathcal{A}\) 为当前 Archive（已记录的成功攻击集合），\(H(\mathbf{p})\) 为策略分布的 Shannon 熵，\(\mathbf{p}_{\mathcal{A}}\) 为 Archive 中各策略槽位的归一化占用频率分布。该定义的核心问题在于：当 Archive 规模 \(|\mathcal{A}|\) 增大时，加入单个样本对分布的扰动为 \(O(1/|\mathcal{A}|)\)，对应的熵变化也是 \(O(1/|\mathcal{A}|)\)，导致训练后期奖励信号持续衰减直至消失（reward vanishing）。

**归一化边际覆盖增益。** 为消除信号衰减，我们以当前 Archive 状态下单个样本可达到的最大熵增量作为归一化基准：

\[
R_{\text{coverage}}(x) = \frac{H(\mathbf{p}_{\mathcal{A} \cup \{x\}}) - H(\mathbf{p}_{\mathcal{A}})}{\max_{b \in \mathcal{B}} \left[H(\mathbf{p}_{\mathcal{A} \cup \{x_b\}}) - H(\mathbf{p}_{\mathcal{A}})\right] + \epsilon}
\]

其中 \(x_b\) 表示一个落入槽位 \(b\) 的假想样本，分母为遍历所有槽位后取得的单步最优边际增益。

**核心逻辑：** 分子为"该样本的实际边际增益"，分母为"当前状态下任何单样本能达到的最佳边际增益"，两者均为 \(O(1/|\mathcal{A}|)\) 量级并同速衰减，比值始终保持 \(O(1)\)，从根本上消除信号随 Archive 增长而衰减的问题。落入当前最优槽位（最低频槽位）的样本得分为 1，落入过度饱和槽位的样本得分为负值，区分度在全训练周期内保持稳定。

**计算复杂度：** 分母需遍历所有 \(|\mathcal{B}|\) 个槽位计算假想加入后的熵增益，每次增量熵计算为 \(O(1)\)，总复杂度为 \(O(|\mathcal{B}|)\)。在典型设置下 \(|\mathcal{B}| = |\mathcal{S}| \times |\mathcal{C}|\) 为百量级，完全可接受。且分母仅依赖当前 Archive 状态，同一 batch 内所有样本共享同一个分母值，只需计算一次。

#### KL 散度视角的理论分析

利用 Shannon 熵与 KL 散度的恒等关系 \(H(\mathbf{p}) = \log|\mathcal{B}| - D_{\text{KL}}(\mathbf{p} \| \mathbf{u})\)（其中 \(\mathbf{u}\) 为策略空间上的均匀分布），边际覆盖增益可等价改写为：

\[
H(\mathbf{p}_{\mathcal{A} \cup \{x\}}) - H(\mathbf{p}_{\mathcal{A}}) = D_{\text{KL}}(\mathbf{p}_{\mathcal{A}} \| \mathbf{u}) - D_{\text{KL}}(\mathbf{p}_{\mathcal{A} \cup \{x\}} \| \mathbf{u})
\]

即边际熵增量等价于加入样本后策略分布与均匀分布之间 KL 散度的下降量。由此，归一化覆盖增益的语义变为**单步 KL 收缩效率**：该样本使策略分布向均匀分布收缩的实际 KL 减少量，占单步最优 KL 减少量的比例。

这一 KL 视角提供了两个理论支撑：

1. **梯度方向解释。** KL 散度对第 \(b\) 个槽位概率的偏导数为 \(\partial D_{\text{KL}}(\mathbf{p} \| \mathbf{u}) / \partial p_b = 1 + \log p_b - \log u_b\)。\(p_b\) 越小（低频槽位），负梯度越大，沿该方向更新带来的 KL 下降越大。这从优化梯度的角度解释了为什么低频槽位获得更高的覆盖度奖励——选择低频槽位等价于选择 KL 散度下降最陡的方向。

2. **Zero-avoiding 特性。** 前向 KL（\(D_{\text{KL}}(\mathbf{p} \| \mathbf{u})\)）具有 zero-avoiding 特性：当某个槽位概率 \(p_b \to 0\) 时，KL 散度趋于极大值。这意味着归一化覆盖增益天然对策略空间中的空白槽位施加最强的探索驱动，与覆盖度目标——避免任何策略区域被完全遗漏——在理论上一致。

### 2.4 当前策略新颖性：频率逆向新颖性（Frequency-Inverse Novelty）

新颖性奖励衡量单个攻击样本相对于全局历史的策略差异程度。我们采用频率逆向新颖性（Frequency-Inverse Novelty），基于 Archive 中各策略的累计频次进行归一化：

\[
R_{\text{novelty}}(x_i) = 1 - \frac{n(b(x_i))}{\max_{b \in \mathcal{B}} n(b)}
\]

其中 \(n(b)\) 为 Archive 中策略 \(b\) 的累计出现频次，\(\max_{b \in \mathcal{B}} n(b)\) 为所有策略中最高频次。

**核心逻辑：** 落入最高频策略的样本获得新颖性 0，落入从未出现过的策略的样本获得新颖性 1，其余策略按频次线性内插。这为攻击者提供了一个始终清晰区分"热门 vs. 冷门"策略的全局信号。

### 2.5 Coverage 与 Novelty 的协同作用

边际覆盖增益和频率逆向新颖性从两个互补的角度驱动攻击多样性：

- **Coverage 提供"去哪里"的方向指引：** 通过边际熵增益，为攻击者标识出对全局策略分布均衡性贡献最大的策略区域（空白或低频槽位），引导攻击者向这些区域探索。
- **Novelty 提供"不要重复去热门区域"的约束：** 通过频率反比惩罚，持续压低攻击者重复选择高频策略的倾向，防止策略坍缩。

两者的合力确保攻击者既有宏观导航信号，又有微观分散约束。同时，Coverage 是样本级信号（每个样本的边际增益不同），Novelty 也是样本级信号（取决于样本所落入槽位的频次），两者都与 GRPO 的 advantage 计算天然兼容——在同一 group 内，落入冷门策略的样本在 Coverage 和 Novelty 上均获得更高奖励，从而获得更大的正向 advantage，梯度更新自然推动攻击者的策略分布向冷门区域扩展。

## 三、贝叶斯对抗回放池

### 3.1 回放池构建

对抗回放池 \(\mathcal{R}\) 存储在攻防对抗过程中成功突破防御者的高风险攻击样本。每轮攻防交互后，攻击成功的样本连同其行为描述符 \(b(x)\) 被加入回放池。回放池的核心目的是为防御者提供多样化的历史对抗经验，缓解因攻击者策略持续演化而导致的防御对抗遗忘（defense adversarial forgetting）。

### 3.2 贝叶斯后验更新（Bayesian Beta-Bernoulli Update）

为每个回放池样本 \(x_i\) 维护成功次数 \(s_i\)（攻破防御者）与失败次数 \(f_i\)（被拒绝）。假设每次攻击成败服从伯努利分布，取共轭 Beta 先验，则后验为：

\[
p_i \mid s_i, f_i \;\sim\; \text{Beta}(\alpha + s_i,\; \beta + f_i)
\]

其中 \(\alpha, \beta > 0\) 为全局先验伪计数（典型取值 \(\alpha = \beta = 1\)，即均匀先验）。

**关键统计量：**

- 后验均值（攻击成功率点估计）：

\[
\hat{p}_i = \frac{\alpha + s_i}{\alpha + \beta + s_i + f_i}
\]

- 后验方差（不确定性度量）：

\[
\text{Var}(p_i) = \frac{(\alpha + s_i)(\beta + f_i)}{(\alpha + \beta + s_i + f_i)^2(\alpha + \beta + s_i + f_i + 1)}
\]

试验次数越多，方差越小，对 \(\hat{p}_i\) 的估计越有信心。

**更新规则：** 标准 Beta-Bernoulli 共轭更新，\(O(1)\)：

\[
\text{攻破防御者（成功）：} \quad s_i \leftarrow s_i + 1
\]

\[
\text{被拒绝（失败）：} \quad f_i \leftarrow f_i + 1
\]

**时间衰减（处理非平稳性）：** 防御者持续训练时，样本的攻击有效性会漂移。引入指数衰减因子 \(\gamma \in (0,1)\)（典型取值 \(\gamma \in [0.95, 0.99]\)），每轮训练开始时对所有样本执行：

\[
s_i \leftarrow \gamma \cdot s_i, \qquad f_i \leftarrow \gamma \cdot f_i
\]

效果是将 \((s_i, f_i)\) 缓慢"遗忘"回先验，使后验能跟踪防御者能力的变化。衰减后 \(s_i, f_i\) 变为非整数，但 Beta 分布参数允许任意正实数，数学上完全合法。

**设计动机：** 相比二元有害性更新（U1，防住即淘汰）和多元有害性等级更新（U2，离散等级缓冲），贝叶斯后验更新具有三个结构性优势：
1. **抗偶然误判：** 后验均值综合了所有历史试验结果，单次防御成功不会导致样本被过早淘汰；试验次数越多，估计越稳定。
2. **非平稳适应：** 时间衰减机制使后验自然跟踪防御者能力的演化，避免历史记录与当前状态互相"污染"。
3. **内建探索-利用平衡：** 后验分布同时提供均值（利用）和方差（探索），天然支持基于不确定性的采样策略。

### 3.3 Thompson Sampling 采样

每轮需从回放池中选取 \(k\) 个样本用于防御者训练时，采用 Thompson Sampling：

1. 对每个样本 \(x_i\)，从其后验中采样：\(\tilde{p}_i \sim \text{Beta}(\alpha + s_i,\; \beta + f_i)\)
2. 按 \(\tilde{p}_i\) 降序取前 \(k\) 个

后验均值高且方差小的样本（多次验证确实危险）大概率抽到高 \(\tilde{p}_i\)——利用；试验次数少、方差大的样本也有机会恰好抽到高值——探索。Thompson Sampling 通过后验采样天然实现探索-利用平衡，无需额外调参。

### 3.4 剪枝策略

移除后验均值极低且已有足够试验的样本：

\[
\text{移除}\; x_i \;\;\text{若}\;\; \hat{p}_i < \epsilon \;\;\text{且}\;\; (s_i + f_i) > n_{\min}
\]

即只有当样本被充分测试（试验次数超过阈值 \(n_{\min}\)）且攻击成功率估计极低（低于阈值 \(\epsilon\)）时，才确信该样本已无威胁价值并将其移除。高不确定性的样本（试验次数少）不会被过早剪枝。

## 四、基于 GDPO 的分组奖励归一化

![alt text](image-1.png)

### 4.1 问题背景：GRPO 多奖励信号坍缩

攻击者的奖励由多个分量组成：攻击有效性 \(R_{\text{effective}}\)、策略覆盖度 \(R_{\text{coverage}}\)、策略新颖性 \(R_{\text{novelty}}\)。标准 GRPO 的做法是先将所有奖励分量求和得到总奖励 \(r_{\text{sum}}\)，再在 group 内进行归一化计算 advantage：

\[
r_{\text{sum}}^{(i,j)} = r_1^{(i,j)} + r_2^{(i,j)} + \cdots + r_n^{(i,j)}, \qquad A_{\text{sum}}^{(i,j)} = \frac{r_{\text{sum}}^{(i,j)} - \text{mean}(\mathbf{r}_{\text{sum}})}{\text{std}(\mathbf{r}_{\text{sum}})}
\]

GDPO 指出，这种"先求和再归一化"的方式会导致多奖励信号坍缩（reward signal collapse）：不同的奖励组合在归一化后可能映射到完全相同的 advantage 值。例如，在两个二元奖励、两个 rollout 的设置下，奖励组合 \((0, 1)\)、\((0, 2)\)、\((1, 2)\) 在 GRPO 归一化后产生相同的 advantage \((-0.7071, 0.7071)\)，而 \((0, 2)\) 本应产生比 \((0, 1)\) 更强的学习信号——因为总奖励 2 意味着同时满足两个奖励目标，而总奖励 1 仅满足其一。这一信号压缩效应在我们的框架中尤为严重，因为 C4 边际覆盖增益在训练中后期的绝对值可能很小，与攻击有效性奖励的量级差异显著，先求和后归一化会使覆盖度信号几乎完全被淹没。

### 4.2 GDPO 的逐奖励解耦归一化

参考 GDPO（Group reward-Decoupled normalization Policy Optimization）的方法，我们对攻击者的多个奖励分量在 group 内逐一独立归一化，再加权聚合并在 batch 级别进行二次归一化，分三步完成 advantage 计算：

**第一步：逐奖励组级归一化。** 对于 group \(\mathcal{G}_i\) 内的每个奖励分量 \(r_k\)（\(k \in \{\text{effective}, \text{coverage}, \text{novelty}\}\)），分别在 group 内部计算均值和标准差并归一化：

\[
A_k^{(i,j)} = \frac{r_k^{(i,j)} - \text{mean}\{r_k^{(i,1)}, \ldots, r_k^{(i,G)}\}}{\text{std}\{r_k^{(i,1)}, \ldots, r_k^{(i,G)}\} + \epsilon}
\]

这一步确保每个奖励维度的组内相对排序信号被独立保留，不受各分量绝对量级差异的影响。即使 C4 覆盖度增益的绝对值远小于攻击有效性奖励，归一化后其组内排序差异（"谁的边际贡献更大"）仍然被清晰地表达。

**第二步：加权聚合。** 将各奖励分量的归一化 advantage 按权重加权求和：

\[
A_{\text{sum}}^{(i,j)} = w_{\text{eff}} \cdot A_{\text{effective}}^{(i,j)} + w_{\text{cov}} \cdot A_{\text{coverage}}^{(i,j)} + w_{\text{nov}} \cdot A_{\text{novelty}}^{(i,j)}
\]

其中 \(w_{\text{eff}}, w_{\text{cov}}, w_{\text{nov}}\) 为各分量的优先级权重。由于每个分量已经过组内标准化，权重直接反映各目标的相对重要性，而非补偿量级差异。

**第三步：批次级 advantage 归一化。** 在整个训练 batch 上对聚合后的 advantage 进行二次归一化：

\[
\hat{A}_{\text{sum}}^{(i,j)} = \frac{A_{\text{sum}}^{(i,j)} - \text{mean}\{A_{\text{sum}}^{(i',j')} \mid i' \in \mathcal{D}_{\text{Batch}},\, j' = 1, \ldots, G\}}{\text{std}\{A_{\text{sum}}^{(i',j')} \mid i' \in \mathcal{D}_{\text{Batch}},\, j' = 1, \ldots, G\} + \epsilon}
\]

这一步确保最终 advantage 的数值范围不会随奖励分量数目的增加而膨胀，维持训练过程中梯度更新幅度的稳定性。GDPO 实验表明，移除这一步会导致训练不稳定甚至收敛失败。

### 4.3 与差异化多样性激励的协同

我们框架中多样性奖励的差异化激励系数（攻击成功 \(\lambda = 1.0\)，失败 \(\lambda = 0.5\)）与 GDPO 的逐奖励归一化天然协同：

- **在 group 内部，** 攻击成功且策略新颖的样本在 \(R_{\text{effective}}\) 和 \(R_{\text{diversity}}\) 两个维度上都获得高原始奖励，经过逐维度独立归一化后，这些样本在两个 advantage 维度上都排名靠前，加权聚合后获得最高的综合 advantage。
- **攻击失败但策略新颖的样本** 在 \(R_{\text{effective}}\) 维度获得低 advantage，但在 \(R_{\text{diversity}}\) 维度（因 \(\lambda = 0.5\) 而折减但非零）仍可获得正向 advantage。逐奖励归一化确保这一折减后的多样性信号不会被有效性维度的数值完全掩盖，为冷门策略方向保留了可传导的梯度。


### 4.4 核心作用总结

GDPO 式的分组归一化在本框架中解决了三个关键问题：

1. **量级差异消除：** Coverage 边际覆盖增益（训练后期可能为 \(10^{-3}\) 量级）与 Novelty 攻击有效性奖励（通常为 \(0/1\) 量级）在独立归一化后处于相同尺度，覆盖度信号不再被淹没。
2. **信号区分度保留：** 不同奖励组合（如"成功+新颖"vs."成功+常见"vs."失败+新颖"）在 GRPO 下可能坍缩为相同 advantage，而在 GDPO 下保持清晰的区分，使策略更新方向更精确。
3. **训练稳定性：** 批次级二次归一化控制了 advantage 的数值范围，防止多奖励叠加导致梯度爆炸或训练震荡。
