# 基于多样性驱动的 LLM 安全攻防协同演化框架

---

## 研究动机

大语言模型（LLM）的安全对齐面临一个根本性的"攻防不对称"困境：攻击者的策略空间几乎无限（任何自然语言表达都可能构成攻击），而防御者必须覆盖全部可能的风险维度。现有基于强化学习的攻防协同训练框架（如 MAGIC）虽然通过让攻击者与防御者交替训练来实现动态博弈，但在实践中暴露出两个核心瓶颈：

**攻击策略坍缩（Attack Strategy Collapse）。** 攻击者在 RL 训练中倾向于过拟合到少数高回报的攻击模式——一旦发现某种策略（如特定的角色扮演话术）能稳定突破防御者，RL 的梯度信号会迅速强化该策略并抑制其他探索。结果是攻击者虽然在训练指标（攻击成功率）上表现良好，但生成的攻击样本在语义和策略维度上高度同质，防御者仅需学会应对少数几种攻击模式即可获得虚高的安全评分。这种"窄攻击训出来的防御者"在面对分布外的新型攻击时极度脆弱。

**防御对抗遗忘（Defense Adversarial Forgetting）。** 防御者在学习应对当前轮次的新攻击时，会逐渐遗忘对早期攻击模式的防御能力。这是因为 RL 的在线训练天然偏向近期数据分布——当攻击者策略演化后，防御者的训练分布随之漂移，早期攻击的梯度信号消失，导致防御者对历史攻击模式的鲁棒性持续退化。

本研究的核心目标是从策略层面系统性地提升攻击多样性，并通过历史对抗经验的有效管理缓解防御遗忘，构建一个攻防双方能力持续且均衡增长的闭环演化系统。

---

## 一、攻防协同演化总览

本框架将 LLM 安全训练建模为攻击者（Attacker）与防御者（Defender）之间的动态对抗博弈。攻防双方各自持有独立模型参数，通过强化学习从对抗交互中提取奖励信号并迭代更新策略。核心设计目标有三：（1）攻击者在显式策略引导和多样性奖励下持续拓展攻击策略空间覆盖；（2）防御者在当前攻击与历史高风险攻击的混合训练下同步提升鲁棒性；（3）对抗回放池动态淘汰过时样本并吸纳新的高风险样本，三者构成闭环演化系统。

整体训练流程采用两阶段交替迭代（Attacker 先手）：

**步骤 1：攻击者策略推理与改写（Stage 1）。** 从种子 prompt 数据集中采样初始 prompt，同时向攻击者提供完整的策略空间描述（如 \(|\mathcal{S}|\) 种风险类别 \(\times\) \(|\mathcal{C}|\) 种攻击方式）。攻击者首先推理选择一种最适合当前 prompt 的攻击策略 \((s, c)\) 作为隐式动作，然后在该策略的引导下将初始 prompt 改写为具有隐蔽性的对抗 prompt。改写后的 prompt 提交给当前版本的防御者生成响应，由安全评估模型对各维度进行评估。根据攻击有效性和攻击多样性计算攻击者的复合奖励，通过 GRPO 更新攻击者策略。攻击成功的样本加入统一攻击档案池。

**步骤 2：防御者混合训练（Stage 2）。** 防御者的每个训练 batch 由两部分混合组成：（1）从种子数据集采样并由当前攻击者生成的新攻击 prompt（批大小 \(B_{\text{train}}\)）；（2）从统一攻击档案池中通过 Thompson Sampling 采样的历史高风险 prompt（批大小 \(B_{\text{replay}}\)，设为 \(B_{\text{train}}/2\) 或 \(B_{\text{train}}/4\)）。防御者在混合 batch 上统一计算奖励并通过 GRPO 更新。对于回放样本，根据防御结果更新其贝叶斯后验并执行剪枝。攻击成功的新样本在阶段结束后加入档案池。

**步骤 3：迭代演化。** 重复步骤 1–2。攻击者在多样性奖励驱动下持续拓展策略空间，防御者在混合训练数据下同步提升——新攻击样本推动防御者适应最新攻击，回放样本巩固历史防御能力——回放池动态进化，形成闭环。

**两阶段设计的优势：** 相比将回放训练独立为第三阶段，将回放样本直接混入防御者训练 batch 有两个好处：一是防御者在每个训练步中同时接触新攻击和历史攻击，在梯度层面自然实现"适应新攻击"与"巩固旧防御"的平衡，避免分阶段训练中两个目标的梯度冲突或顺序偏差；二是防御者通过混合 batch 获得比攻击者更大的有效训练批量（\(B_{\text{train}} + B_{\text{replay}}\)），增强了每步更新的样本多样性和梯度稳定性。

## 二、显式攻击策略引导与多样性奖励

### 2.1 攻击策略空间定义

我们定义攻击策略空间 \(\mathcal{B} = \mathcal{S} \times \mathcal{C}\)，其中 \(\mathcal{S}\) 为风险类别集合（如暴力犯罪、非暴力犯罪、性相关犯罪、自残自杀、仇恨歧视、危险物质与武器等），\(\mathcal{C}\) 为攻击方式集合（如角色扮演、权威操纵、术语伪装、故事嵌入、逻辑诱导等）。每个攻击样本 \(x\) 被映射到策略空间中的一个行为描述符 \(b(x) = (s, c) \in \mathcal{B}\)。

在攻击者的输入 prompt 中，我们直接提供完整的策略空间描述（所有 \(|\mathcal{S}| \times |\mathcal{C}|\) 种策略组合的定义和示例）。攻击者需要：（1）根据原始 prompt 的内容推理选择一种最合适的攻击策略；（2）在所选策略的引导下将原始 prompt 改写为具有隐蔽性的有害 prompt。行为描述符的评估由安全分类模型（风险类别 \(s\)）和 LLM Judge（攻击方式 \(c\)）分别判定（更正：直接从攻击者回复中正则提取！）。

### 2.2 攻击者奖励结构

攻击者的总奖励由攻击有效性奖励和攻击多样性奖励两部分组成。多样性奖励对攻击成功与失败的样本施加不同的激励强度——成功样本获得完整的多样性奖励，失败样本获得折减的多样性奖励，确保多样性探索优先服务于攻击有效性，同时不完全放弃对失败样本的策略分散引导：

\[
R_{\text{attack}}(x) = R_{\text{effective}}(x) + \lambda(x) \cdot R_{\text{diversity}}(x)
\]

其中多样性激励系数 \(\lambda(x)\) 根据攻击成败进行差异化设置：

\[
\lambda(x) = \begin{cases} 1.0 & \text{if attack\_success}(x) \\ 0.5 & \text{otherwise} \end{cases}
\]

**差异化激励的设计动机：**

- **攻击成功样本（\(\lambda = 1.0\)）：** 这些样本已验证对防御者具有实际威胁，其策略选择具有安全评估价值。给予完整的多样性奖励，最大化激励攻击者在有效攻击的前提下拓展策略覆盖。
- **攻击失败样本（\(\lambda = 0.5\)）：** 此前的设计将失败样本的多样性奖励完全屏蔽（\(\lambda = 0\)），但这会导致一个问题：如果某个冷门策略在当前阶段尚未学会有效攻击，其探索信号会完全消失，攻击者将迅速放弃对该策略方向的尝试。保留折减的多样性奖励（\(\lambda = 0.5\)）可以在不过度激励无效攻击的前提下，为冷门策略方向维持基本的探索压力，给予攻击者继续尝试和改进的梯度信号。
- **有效性优先原则：** \(\lambda_{\text{success}} = 2 \times \lambda_{\text{fail}}\) 的比例确保，在 GRPO 的 group 内 advantage 计算中，攻击成功且策略新颖的样本相比攻击失败但策略新颖的样本获得显著更高的综合 advantage，从而在梯度更新中优先强化"既有效又多样"的攻击行为。


### 2.3 多样性奖励定义：策略空间覆盖度（Coverage）

覆盖度奖励衡量攻击策略对行为空间 \(\mathcal{B}\) 的整体覆盖与均衡程度，是本框架采用的主要多样性指标。

#### 原始定义及其局限

基础的边际覆盖增益直接度量单个样本对全局策略分布熵的边际贡献：

\[
R_{\text{coverage}}^{\text{raw}}(x) = H(\mathbf{p}_{\mathcal{A} \cup \{x\}}) - H(\mathbf{p}_{\mathcal{A}})
\]

其中 \(\mathcal{A}\) 为当前统一攻击档案池（已记录的成功攻击集合），\(H(\mathbf{p})\) 为策略分布的 Shannon 熵，\(\mathbf{p}_{\mathcal{A}}\) 为档案池中各策略槽位的归一化占用频率分布。该定义的核心问题在于：当档案池规模 \(|\mathcal{A}|\) 增大时，加入单个样本对分布的扰动为 \(O(1/|\mathcal{A}|)\)，对应的熵变化也是 \(O(1/|\mathcal{A}|)\)，导致训练后期奖励信号持续衰减直至消失（reward vanishing）。

#### 归一化边际覆盖增益（Normalized Marginal Coverage Gain）

为消除信号衰减，我们以当前档案池状态下单个样本可达到的最大熵增量作为归一化基准：

\[
R_{\text{coverage}}(x) = \frac{H(\mathbf{p}_{\mathcal{A} \cup \{x\}}) - H(\mathbf{p}_{\mathcal{A}})}{\max_{b \in \mathcal{B}} \left[H(\mathbf{p}_{\mathcal{A} \cup \{x_b\}}) - H(\mathbf{p}_{\mathcal{A}})\right] + \epsilon}
\]

其中 \(x_b\) 表示一个落入槽位 \(b\) 的假想样本，分母为遍历所有槽位后取得的单步最优边际增益。

**核心逻辑：** 分子为"该样本的实际边际增益"，分母为"当前状态下任何单样本能达到的最佳边际增益"，两者均为 \(O(1/|\mathcal{A}|)\) 量级并同速衰减，比值始终保持 \(O(1)\)，从根本上消除信号随档案池增长而衰减的问题。落入当前最优槽位（最低频槽位）的样本得分为 1，落入过度饱和槽位的样本得分为负值，区分度在全训练周期内保持稳定。

**计算复杂度：** 分母需遍历所有 \(|\mathcal{B}|\) 个槽位计算假想加入后的熵增益，每次增量熵计算为 \(O(1)\)，总复杂度为 \(O(|\mathcal{B}|)\)。在典型设置下 \(|\mathcal{B}| = |\mathcal{S}| \times |\mathcal{C}|\) 为百量级，完全可接受。且分母仅依赖当前档案池状态，同一 batch 内所有样本共享同一个分母值，只需计算一次。

#### KL 散度视角的理论分析

利用 Shannon 熵与 KL 散度的恒等关系 \(H(\mathbf{p}) = \log|\mathcal{B}| - D_{\text{KL}}(\mathbf{p} \| \mathbf{u})\)（其中 \(\mathbf{u}\) 为策略空间上的均匀分布），边际覆盖增益可等价改写为：

\[
H(\mathbf{p}_{\mathcal{A} \cup \{x\}}) - H(\mathbf{p}_{\mathcal{A}}) = D_{\text{KL}}(\mathbf{p}_{\mathcal{A}} \| \mathbf{u}) - D_{\text{KL}}(\mathbf{p}_{\mathcal{A} \cup \{x\}} \| \mathbf{u})
\]

即边际熵增量等价于加入样本后策略分布与均匀分布之间 KL 散度的下降量。由此，归一化覆盖增益的语义变为**单步 KL 收缩效率**：该样本使策略分布向均匀分布收缩的实际 KL 减少量，占单步最优 KL 减少量的比例。

这一 KL 视角提供了两个理论支撑：

1. **梯度方向解释。** KL 散度对第 \(b\) 个槽位概率的偏导数为 \(\partial D_{\text{KL}}(\mathbf{p} \| \mathbf{u}) / \partial p_b = 1 + \log p_b - \log u_b\)。\(p_b\) 越小（低频槽位），负梯度越大，沿该方向更新带来的 KL 下降越大。这从优化梯度的角度解释了为什么低频槽位获得更高的覆盖度奖励——选择低频槽位等价于选择 KL 散度下降最陡的方向。

2. **Zero-avoiding 特性。** 前向 KL（\(D_{\text{KL}}(\mathbf{p} \| \mathbf{u})\)）具有 zero-avoiding 特性：当某个槽位概率 \(p_b \to 0\) 时，KL 散度趋于极大值。这意味着归一化覆盖增益天然对策略空间中的空白槽位施加最强的探索驱动，与覆盖度目标——避免任何策略区域被完全遗漏——在理论上一致。

### 2.4 可选多样性定义：频率逆向新颖性（Frequency-Inverse Novelty）

频率逆向新颖性提供了一种更简洁的多样性度量方式，可作为覆盖度定义的替代选项。该指标基于档案池中各策略的累计频次进行归一化：

\[
R_{\text{novelty}}(x_i) = 1 - \frac{n(b(x_i))}{\max_{b \in \mathcal{B}} n(b)}
\]

其中 \(n(b)\) 为档案池中策略 \(b\) 的累计出现频次，\(\max_{b \in \mathcal{B}} n(b)\) 为所有策略中最高频次。

**核心逻辑：** 落入最高频策略的样本获得新颖性 0，落入从未出现过的策略的样本获得新颖性 1，其余策略按频次线性内插。这为攻击者提供了一个始终清晰区分"热门 vs. 冷门"策略的全局信号。

### 2.5 Coverage 与 Novelty 的对比

覆盖度（Coverage）和新颖性（Novelty）是攻击多样性奖励的两种可选定义，两者具有相似的多样性激励机制——都通过频次信号鼓励低频策略、抑制高频策略——但在定义复杂度和理论基础上有所差异：

- **Coverage（归一化边际覆盖增益）** 基于信息论中的 Shannon 熵边际增量，通过单步最优增益归一化消除 reward vanishing，提供严格的 KL 散度收缩效率解读。其优势在于：归一化机制保证信号量级在全训练周期内稳定，且 KL 视角提供了梯度方向（低频 = 最陡下降）和 zero-avoiding（空白槽位 = 最强驱动）两层理论支撑。相应地，定义和计算相对复杂（需维护 Archive 分布、遍历槽位计算最优增益）。
- **Novelty（频率逆向新颖性）** 直接基于频次线性归一化，定义简洁、计算高效（\(O(1)\)）、无额外超参。作为可选替代方案，适用于对理论严格性要求较低或需要快速验证的场景。

本框架以 Coverage 作为主线多样性指标，因为其信号稳定性和理论可解释性更适合长周期攻防协同训练中的奖励设计需求。

## 三、贝叶斯对抗回放池

### 3.1 回放池构建

统一攻击档案池 \(\mathcal{A}\) 同时承担策略频次记录（用于多样性奖励计算）和对抗回放（用于防御者补充训练）两项功能。池中存储在攻防对抗过程中成功突破防御者的高风险攻击 prompt（不含防御者回复）。每轮攻防交互后，攻击成功的样本连同其行为描述符 \(b(x)\) 被加入档案池。回放的核心目的是为防御者提供多样化的历史对抗经验，缓解因攻击者策略持续演化而导致的防御对抗遗忘（defense adversarial forgetting）。

### 3.2 贝叶斯后验更新（Bayesian Beta-Bernoulli Update）

为档案池中每个样本 \(x_i\) 维护成功次数 \(s_i\)（攻破防御者）与失败次数 \(f_i\)（被拒绝）。假设每次攻击成败服从伯努利分布，取共轭 Beta 先验，则后验为：

\[
p_i \mid s_i, f_i \;\sim\; \text{Beta}(\alpha + s_i,\; \beta + f_i)
\]

其中 \(\alpha, \beta > 0\) 为全局先验伪计数（典型取值 \(\alpha = \beta = 1\)，即均匀先验）。

**关键统计量：**

- 后验均值（攻击成功率点估计）：

\[
\hat{p}_i = \frac{\alpha + s_i}{\alpha + \beta + s_i + f_i}
\]

- 后验方差（不确定性度量）：

\[
\text{Var}(p_i) = \frac{(\alpha + s_i)(\beta + f_i)}{(\alpha + \beta + s_i + f_i)^2(\alpha + \beta + s_i + f_i + 1)}
\]

试验次数越多，方差越小，对 \(\hat{p}_i\) 的估计越有信心。

**更新规则：** 标准 Beta-Bernoulli 共轭更新，\(O(1)\)：

\[
\text{攻破防御者（成功）：} \quad s_i \leftarrow s_i + 1
\]

\[
\text{被拒绝（失败）：} \quad f_i \leftarrow f_i + 1
\]

**时间衰减（处理非平稳性）：** 防御者持续训练时，样本的攻击有效性会漂移。引入指数衰减因子 \(\gamma \in (0,1)\)（典型取值 \(\gamma \in [0.95, 0.99]\)），每轮训练开始时对所有样本执行：

\[
s_i \leftarrow \gamma \cdot s_i, \qquad f_i \leftarrow \gamma \cdot f_i
\]

效果是将 \((s_i, f_i)\) 缓慢"遗忘"回先验，使后验能跟踪防御者能力的变化。衰减后 \(s_i, f_i\) 变为非整数，但 Beta 分布参数允许任意正实数，数学上完全合法。

**设计动机：** 相比二元有害性更新（U1，防住即淘汰）和多元有害性等级更新（U2，离散等级缓冲），贝叶斯后验更新具有三个结构性优势：
1. **抗偶然误判：** 后验均值综合了所有历史试验结果，单次防御成功不会导致样本被过早淘汰；试验次数越多，估计越稳定。
2. **非平稳适应：** 时间衰减机制使后验自然跟踪防御者能力的演化，避免历史记录与当前状态互相"污染"。
3. **内建探索-利用平衡：** 后验分布同时提供均值（利用）和方差（探索），天然支持基于不确定性的采样策略。

### 3.3 Thompson Sampling 采样

每个防御者训练 batch 中需从档案池中采样 \(B_{\text{replay}}\) 个回放样本时，采用 Thompson Sampling：

1. 对每个样本 \(x_i\)，从其后验中采样：\(\tilde{p}_i \sim \text{Beta}(\alpha + s_i,\; \beta + f_i)\)
2. 按 \(\tilde{p}_i\) 降序取前 \(B_{\text{replay}}\) 个

后验均值高且方差小的样本（多次验证确实危险）大概率抽到高 \(\tilde{p}_i\)——利用；试验次数少、方差大的样本也有机会恰好抽到高值——探索。Thompson Sampling 通过后验采样天然实现探索-利用平衡，无需额外调参。

### 3.4 剪枝策略

移除后验均值极低且已有足够试验的样本：

\[
\text{移除}\; x_i \;\;\text{若}\;\; \hat{p}_i < \epsilon \;\;\text{且}\;\; (s_i + f_i) > n_{\min}
\]

即只有当样本被充分测试（试验次数超过阈值 \(n_{\min}\)）且攻击成功率估计极低（低于阈值 \(\epsilon\)）时，才确信该样本已无威胁价值并将其移除。高不确定性的样本（试验次数少）不会被过早剪枝。
