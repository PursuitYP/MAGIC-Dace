Diversity-Driven LLM Safety Co-Evolution

基于多样性驱动的 LLM 安全攻防协同演化框架 — 伪代码 v3.1（两阶段，混合 batch 防御者训练）

定义 1：攻击策略空间

二维攻击策略空间 $\mathcal{B} = \mathcal{S} \times \mathcal{C}$，$\mathcal{S}$ = 风险类别（$|\mathcal{S}|$ 类），$\mathcal{C}$ = 攻击方式（$|\mathcal{C}|$ 种）。每个攻击样本 $x$ 映射到 $b(x) = (s,c) \in \mathcal{B}$。

定义 2：统一攻击档案池（Archive & Replay Pool）

统一攻击档案池 $\mathcal{A}$ 同时承担策略频次记录（多样性奖励）与贝叶斯回放（防御者补训）两项功能。池中存储所有攻击成功的改写 prompt（不含防御者回复），每个样本 $x_i$ 维护：

  • 策略频次：$b(x_i)$ 所在槽位的累计频次 $n(b)$，用于计算策略分布 $\mathbf{p}_{\mathcal{A}}$ 与多样性奖励
  • Beta-Bernoulli 后验：$p_i \mid s_i, f_i \;\sim\; \text{Beta}(\alpha + s_i,\; \beta + f_i)$，其中 $s_i$、$f_i$ 分别为该样本的衰减累计攻破次数与拒绝次数
  • 后验均值 $\hat{p}_i$（posterior mean）：衡量样本 $x_i$ 对当前防御者的期望攻破概率，公式为
    $\hat{p}_i = \dfrac{\alpha + s_i}{\alpha + s_i + \beta + f_i}$
    用于剪枝判断——后验均值极低的样本表明防御者已充分掌握该攻击模式，应从池中移除
  • Thompson 采样值 $\tilde{p}_i$（sampled risk score）：从后验分布中随机采样的一次抽样值 $\tilde{p}_i \sim \text{Beta}(\alpha\!+\!s_i, \beta\!+\!f_i)$，用于回放采样——通过随机性实现探索-利用平衡，偏好不确定性高或期望攻破概率高的样本

入池：Stage 1 / Stage 2 训练结束后，各自将本阶段攻击成功样本放入池中

时间衰减：处理非平稳性，每轮开始 $s_i \leftarrow \gamma s_i$，$f_i \leftarrow \gamma f_i$（$\gamma \in [0.95,0.99]$）

剪枝：$\hat{p}_i < \epsilon$ 且 $(s_i\!+\!f_i) > n_{\min}$ 时移除，保持池中样本对当前防御者的有效性

定义 3：奖励设计

参考 MAGIC 的零和博弈奖励结构。攻防双方的 harmfulness 奖励 $R_{\text{harm}}$ 与 refusal 奖励 $R_{\text{ref}}$ 互为相反数：

$R_D = R_{\text{harm}}(y_D) + R_{\text{ref}}(y_D)$
$R_A = \underbrace{-R_{\text{harm}}(y_D) - R_{\text{ref}}(y_D)}_{\text{零和部分}~=~-R_D} + R_{\text{fmt}}(y_A) + \lambda \cdot R_{\text{div}}(x)$
  • $R_{\text{harm}}$：防御者响应安全性（safe → $+r_{\text{harm}}$，harmful → $-r_{\text{harm}}$）
  • $R_{\text{ref}}$：拒答校准（正确拒答/正确回答 → $+r_{\text{ref}}$，错误拒答/错误回答 → $-r_{\text{ref}}$）
  • $R_{\text{fmt}}$：攻击者格式合规奖励（仅攻击者）
  • $R_{\text{div}}$：归一化边际覆盖增益（仅攻击者），$\lambda$ 根据攻击成败差异化（成功 $1.0$，失败 $0.5$）

定义 4：归一化边际覆盖增益（多样性奖励，Coverage）

$R_{\text{div}}(x) = \dfrac{H(\mathbf{p}_{\mathcal{A} \cup \{x\}}) - H(\mathbf{p}_{\mathcal{A}})}{\max_{b \in \mathcal{B}} \bigl[H(\mathbf{p}_{\mathcal{A} \cup \{x_b\}}) - H(\mathbf{p}_{\mathcal{A}})\bigr] + \epsilon}$
  • 分子 = 样本 $x$ 的实际边际熵增；分母 = 当前档案池下单步最优边际增益（batch 内共享）
  • 两者均为 $O(1/|\mathcal{A}|)$，比值恒为 $O(1)$，消除 reward vanishing
  • 落入低频槽位 → 高奖励（≈1）；落入饱和槽位 → 低/负奖励
  • KL 视角：等价于单步 KL 收缩效率——样本使 $\mathbf{p}_{\mathcal{A}}$ 向均匀分布 $\mathbf{u}$ 收缩的实际 KL 减少量占单步最优减少量的比例
Algorithm 1  多样性驱动的 LLM 安全攻防协同演化（两阶段，Attacker 先手，混合 batch 防御者训练）
Require: 攻击者 $\pi_A$，防御者 $\pi_D$，种子数据集 $\mathcal{D}_{\text{RL}}$，攻击策略空间 $\mathcal{B} = \mathcal{S} \times \mathcal{C}$，Safety Judge $J$，统一攻击档案池 $\mathcal{A} \leftarrow \emptyset$，
    每阶段训练步数 $T$，GRPO 组大小 $G$，轮数 $K$，训练批大小 $B_{\text{train}}$，回放批大小 $B_{\text{replay}}$（$= B_{\text{train}}/2$ 或 $B_{\text{train}}/4$）
Phase 1: Initialization
1$\pi_A \leftarrow \text{SFT}(\pi_A, \mathcal{D}_{\text{sft}})$ // 攻击者 SFT 热启动
2$\pi_D \leftarrow$ Base Model
Phase 2: Co-evolution
3for round $k = 1$ to $K$ do
// ── 每轮开始：对池中所有样本执行时间衰减 ──
4for each $x_i \in \mathcal{A}$ do $s_i \leftarrow \gamma\, s_i$，$f_i \leftarrow \gamma\, f_i$
Stage 1 攻击者训练（固定 $\pi_D$）
5for $t = 1$ to $T$ do
6采样种子 batch $\{q_i\}_{i=1}^{B_{\text{train}}} \sim \mathcal{D}_{\text{RL}}$
7for each seed $q_i$ do
8攻击者生成 $G$ 个 rollout：$\{x_i^{(g)}\}_{g=1}^G \sim \pi_A(\cdot \mid q_i,\, \mathcal{B})$
// 攻击者推理选择策略 $(s,c)$ 并改写 prompt
9防御者生成单条响应：$y_i^{(g)} \sim \pi_D(\cdot \mid x_i^{(g)})$
10评估行为描述符：$b(x_i^{(g)}) \leftarrow RE(x_i^{(g)})$ // 从攻击者回复中正则提取
11判定攻击成败：$\text{succ}_i^{(g)} \leftarrow J(y_i^{(g)}) = \texttt{harmful}$
// ── 攻击者奖励 ──
12$r_{\text{harm}} \leftarrow R_{\text{harm}}(y_i^{(g)})$，$r_{\text{ref}} \leftarrow R_{\text{ref}}(y_i^{(g)})$
13$r_{\text{fmt}} \leftarrow R_{\text{fmt}}(x_i^{(g)})$
14$\Delta_{\max} \leftarrow \max_{b \in \mathcal{B}}[H(\mathbf{p}_{\mathcal{A} \cup \{x_b\}}) - H(\mathbf{p}_{\mathcal{A}})]$ // 单步最优熵增（batch 共享）
15$r_{\text{div}} \leftarrow [H(\mathbf{p}_{\mathcal{A} \cup \{x_i^{(g)}\}}) - H(\mathbf{p}_{\mathcal{A}})] \;/\; (\Delta_{\max} + \epsilon)$
16$\lambda \leftarrow$ if $\text{succ}$ then $1.0$ else $0.5$ // 差异化多样性系数
17$R_A^{(g)} \leftarrow (-r_{\text{harm}} - r_{\text{ref}}) + r_{\text{fmt}} + \lambda \cdot r_{\text{div}}$
18$\pi_A \leftarrow$ GRPO-Update$(\pi_A,\; \{R_A^{(g)}\})$
// ── Stage 1 结束：攻击成功样本入池 ──
19for each 本阶段攻击成功样本 $x$ do
20if $x \notin \mathcal{A}$ then $\mathcal{A} \leftarrow \mathcal{A} \cup \{(x,\, b(x),\, s\!=\!1,\, f\!=\!0)\}$
21else $s_x \leftarrow s_x + 1$ // 已存在则累加成功计数
Stage 2 防御者训练（固定 $\pi_A$，新攻击 + 回放混合 batch）
22for $t = 1$ to $T$ do
// ── 新攻击部分：$B_{\text{train}}$ 个样本 ──
23采样种子 batch $\{q_i\}_{i=1}^{B_{\text{train}}} \sim \mathcal{D}_{\text{RL}}$
24for each seed $q_i$ do
25攻击者生成单条攻击：$x_i \sim \pi_A(\cdot \mid q_i,\, \mathcal{B})$
26防御者生成 $G$ 个 rollout：$\{y_i^{(g)}\}_{g=1}^G \sim \pi_D(\cdot \mid x_i)$
27$R_{D,\text{new}}^{(g)} \leftarrow R_{\text{harm}}(y_i^{(g)}) + R_{\text{ref}}(y_i^{(g)})$
// ── 回放部分：仅当档案池足够时执行 ──
28if $|\mathcal{A}| \geq B_{\text{replay}}$ then
29for each $x_j \in \mathcal{A}$ do $\tilde{p}_j \sim \text{Beta}(\alpha + s_j,\, \beta + f_j)$ // 采样风险分数
30$\mathcal{D}_{\text{replay}} \leftarrow \text{Top-}B_{\text{replay}}\bigl(\{\tilde{p}_j\}\bigr)$ // 取采样值最高的 $B_{\text{replay}}$ 个样本
31for each $x_j \in \mathcal{D}_{\text{replay}}$ do
32 防御者生成 $G$ 个 rollout：$\{y_j^{(g)}\}_{g=1}^G \sim \pi_D(\cdot \mid x_j)$
33 $R_{D,\text{replay}}^{(g)} \leftarrow R_{\text{harm}}(y_j^{(g)}) + R_{\text{ref}}(y_j^{(g)})$
 // 贝叶斯后验更新
34 if $\exists\, g:\; J(y_j^{(g)}) = \texttt{harmful}$ then $s_j \leftarrow s_j + 1$ // 仍被攻破
35 else $f_j \leftarrow f_j + 1$ // 已防住
// ── 更新防御者 ──
36if $|\mathcal{A}| \geq B_{\text{replay}}$ then // 混合 batch 更新
37$\pi_D \leftarrow$ GRPO-Update$\bigl(\pi_D,\; \{R_{D,\text{new}}^{(g)}\} \cup \{R_{D,\text{replay}}^{(g)}\}\bigr)$ // 有效 batch = $B_{\text{train}} + B_{\text{replay}}$
38else // 池不足，仅用新攻击更新
39$\pi_D \leftarrow$ GRPO-Update$\bigl(\pi_D,\; \{R_{D,\text{new}}^{(g)}\}\bigr)$ // 有效 batch = $B_{\text{train}}$
// ── 每 batch 后更新回放样本后验均值并剪枝 ──
40if $|\mathcal{A}| \geq B_{\text{replay}}$ then
41for each $x_j \in \mathcal{D}_{\text{replay}}$: 更新 $\hat{p}_j \leftarrow (\alpha + s_j) \;/\; (\alpha + s_j + \beta + f_j)$
42for each $x_j \in \mathcal{D}_{\text{replay}}$: if $\hat{p}_j < \epsilon$ and $(s_j\!+\!f_j) > n_{\min}$ then $\mathcal{A} \leftarrow \mathcal{A} \setminus \{x_j\}$
// ── Stage 2 结束：新攻击成功样本入池 ──
43for each 本阶段新攻击成功样本 $x$（$\exists\, g:\; J(y^{(g)}) = \texttt{harmful}$）do
44if $x \notin \mathcal{A}$ then $\mathcal{A} \leftarrow \mathcal{A} \cup \{(x,\, b(x),\, s\!=\!1,\, f\!=\!0)\}$
45else $s_x \leftarrow s_x + 1$
46Return $\pi_A,\; \pi_D$
与 MAGIC 的关键差异：
① 训练顺序：MAGIC 为 Defender → Attacker（防御者先手），本方法改为 Attacker → Defender（攻击者先手）。
② 攻击多样性：新增显式二维策略空间 $\mathcal{B} = \mathcal{S} \times \mathcal{C}$ 引导 + 归一化边际覆盖增益（Coverage）作为多样性奖励。攻击者奖励 $R_A = -R_D + R_{\text{fmt}} + \lambda \cdot R_{\text{div}}$，其中 $-R_D$ 保持零和结构。
③ 两阶段混合训练：Stage 1 为攻击者 RL 训练（batch size $B_{\text{train}}$）；Stage 2 为防御者混合训练，当档案池满足 $|\mathcal{A}| \geq B_{\text{replay}}$ 时，每个 batch 由 $B_{\text{train}}$ 个新攻击 + $B_{\text{replay}}$ 个回放样本组成（有效 batch = $B_{\text{train}} + B_{\text{replay}}$）；池不足时仅使用新攻击训练。
④ 统一攻击档案池：将 Archive 与回放池合并为统一的 $\mathcal{A}$，同时承担策略频次记录（多样性奖励）与贝叶斯回放（防御者补训）两项功能。每个 batch 后更新回放样本的后验均值并即时剪枝。
