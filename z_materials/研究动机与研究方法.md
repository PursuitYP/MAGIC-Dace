# 基于强化学习的 LLM 安全多样性攻防协同演化框架

## 一、研究动机

### 1.1 现有攻防协同框架的基本范式与核心局限

近年来，以强化学习驱动的 LLM 安全攻防协同训练逐渐成为安全对齐领域的重要范式。在该范式下，攻击者（Attacker）和防御者（Defender）被建模为一个双人零和博弈（two-player zero-sum game）中的对抗双方：攻击者将初始 prompt 改写为具有隐蔽性的有害 prompt，旨在诱导防御者输出有害回答；防御者针对改写后的 prompt 进行回答，旨在拒绝有害请求并完成正常任务。双方通过强化学习从对抗交互中提取奖励信号并各自优化策略，攻击者的奖励通常包含改写一致性（consistency）和攻击成功率（harmfulness），防御者的奖励通常包含安全拒答率（safety）和任务完成度（helpfulness）。Self-RedTeam 从博弈论角度证明，若攻防双方策略收敛至 Nash 均衡，则防御者可对任意对抗输入生成安全响应，为自博弈安全训练提供了理论基础。后续工作如 MAGIC 进一步将攻防交互建模为非对称序贯博弈（asymmetric sequential game），赋予攻防双方独立的模型参数和差异化的奖励结构，以更贴合现实中攻击者先手、防御者后手的交互本质。

然而，现有攻防协同工作在取得安全性提升的同时，普遍面临两个核心问题：

**（1）攻击策略坍缩（Attack Strategy Collapse）。** 在强化学习训练过程中，攻击者倾向于过拟合到少数高回报的攻击模式上，导致攻击策略的多样性急剧下降。Self-RedTeam 的实验表明，当攻击者仅面对静态防御者时，其生成的攻击在训练后期会收敛至几种占主导地位的模式（如"虚假信息运动""社交媒体引诱"等），在 t-SNE 语义空间中表现为明显的聚类坍缩。QDRT 同样指出，现有基于 RL 的红队生成器虽然能提高攻击成功率，但会产生高度同质化的 prompt，本质上是 RL 奖励最大化范式与多样性探索目标之间的结构性矛盾。Active Attacks 进一步明确提出，红队攻击并非纯粹的奖励最大化问题，而应被视为多样性导向的奖励采样问题（diversity-seeking reward sampling problem），仅最大化毒性奖励会驱使攻击者利用少数高回报模式，从而产生有限覆盖。

**（2）防御对抗遗忘（Defense Adversarial Forgetting）。** 随着攻击策略的持续演化，防御者在学习应对新型攻击的同时，可能逐渐遗忘对旧有攻击模式的防御能力。SSP（Safety Self-Play）的实验观察到，当缺乏经验回放机制时，攻防双方的奖励曲线呈现剧烈震荡，表明防御者在没有历史对抗经验的情况下容易过拟合于当前攻击者的最新策略，导致对先前已学习到的防御模式产生灾难性遗忘。这一问题与持续学习（continual learning）中的经典遗忘困境高度类似，但在对抗训练环境下因对手策略的非平稳性而被进一步放大。

### 1.2 现有多样性探索方法的不足

针对攻击策略坍缩问题，已有工作从不同路径尝试引入多样性：

**（a）基于 Quality-Diversity 的进化搜索方法。** Rainbow Teaming 首次将对抗 prompt 生成形式化为 Quality-Diversity（QD）优化问题，基于 MAP-Elites 算法在预定义的二维行为空间（风险类别 × 攻击风格）中维护一个 Archive，通过进化变异迭代填充高质量攻击。Ruby Teaming 在此基础上引入记忆缓存作为第三个行为维度以提升搜索效率，RainbowPlus 采用进化质量-多样性搜索进一步增强 prompt 变异质量。然而，这类方法通常以固定的 Target LLM 作为攻击目标进行红队搜索，未考虑防御者的动态演化，因此在攻防协同场景下难以持续暴露不断进化的防御者的新漏洞。此外，此类方法的搜索过程不涉及攻击者模型的参数训练，本质上属于 prompt 层面的优化而非生成器层面的学习，难以泛化到新的攻击分布。

**（b）基于 RL 的多样性奖励方法。** Curiosity-driven Red-teaming 通过在 PPO 训练中引入新颖性奖励（novelty reward）鼓励攻击者探索不同于已有攻击的语义空间区域。Learning Diverse Attacks 提出使用 GFlowNets 替代标准 RL 以实现多模式采样，从而在优化攻击成功率的同时保持输出多样性。OpenAI 的 Diverse and Effective Red Teaming 则设计了多步 RL 训练流程，攻击者在每步中生成新攻击的同时被奖励其与历史攻击的差异性。然而，上述方法对多样性的衡量主要依赖表层文本指标（如 Self-BLEU、Distinct-n）或语义嵌入距离（如 SBERT cosine distance），这些指标难以捕捉攻击策略层面的实质差异——攻击者可能仅通过改变词汇和表达方式获得高多样性分数，而实际采用的攻击策略并未改变，即"换皮不换招"问题。

**（c）基于行为空间的策略多样性方法。** QDRT 首次在 RL 红队生成器训练中引入目标驱动的行为多样性（goal-driven diversity），定义基于风险类别和攻击风格的结构化行为空间，通过行为条件化训练（behavior-conditioned training）显式引导攻击者生成覆盖不同行为组合的攻击。ACE-Safety 则将策略引导的蒙特卡洛树搜索（GS-MCTS）与课程强化学习（AC-TGPO）相结合，通过分组感知的策略搜索来探索多样化的越狱策略。然而，这些方法要么仅面向静态目标模型进行红队训练（QDRT），要么虽考虑了攻防联合训练但未系统性地建立攻击多样性与防御鲁棒性之间的双向促进机制（ACE-Safety），尚未实现真正意义上的"多样性驱动的攻防协同演化"。

### 1.3 现有攻防协同工作缺乏系统性多样性机制

将视角聚焦到攻防协同训练框架，可以发现现有工作对多样性问题的处理较为粗糙。Self-RedTeam 虽然在实验中观察到了自博弈训练带来的隐式多样性提升（SBERT 多样性提升 17.8%），但其训练框架中并无显式的多样性优化目标；MAGIC 关注到了攻击者通过 RL 训练涌现出组合式攻击策略的现象，但同样未将多样性纳入奖励设计。AdvEvo-MARL 引入了组内平均回报作为公共基线来稳定训练，但其多样性机制仅限于使用 SFT 种子池中的预定义攻击策略进行热启动，训练过程中缺乏持续的多样性驱动。SSP 提出了反思式经验回放（Reflective Experience Replay）结合 UCB 采样来缓解防御遗忘，但其经验池的管理仅基于奖励值高低，未考虑攻击策略层面的多样性覆盖。

从 MARL 领域的多样性研究来看，传统 PSRO（Policy Space Response Oracles）框架下的多样性目标可归纳为四类：对手采样多样性（opponent diversity）、有效多样性（effective diversity）、响应多样性（response diversity）和行为多样性（behavioral diversity）。现有 LLM 安全攻防工作对多样性的利用大多停留在文本层面和语义层面，尚未建立与 MARL 策略空间多样性理论的系统性联接。这导致攻击策略的演化缺乏结构化的覆盖目标，防御模型的训练缺乏多样化对抗经验的有效管理机制。

### 1.4 本文工作的核心思路

基于以上分析，我们提出从**策略空间多样性**的角度系统性地加强攻防对抗系统的协同演化能力。核心思路包含三个相互关联的组成部分：

**第一，结构化的攻击策略空间与显式的多样性奖励。** 我们引入基于 [风险类别 × 攻击方式] 的二维攻击策略空间，在 RL 训练的奖励函数中融入策略空间覆盖度和当前策略新颖性两类多样性信号，从策略层面而非文本层面激励攻击者的行为多样性。多样性奖励仅在攻击成功时激活，确保多样性探索以有效性为前提，避免产生"多样但无效"的冗余攻击。

**第二，对抗回放池（Adversarial Replay Buffer）与动态采样机制。** 为克服防御者的对抗遗忘问题，我们维护一个对抗回放池，将高攻击成功率的历史攻击样本持续保留，并通过 UCB 采样策略在防御者训练时动态混入历史高风险攻击。回放池采用多元有害性评分机制进行动态更新，使历史攻击样本的保留与淘汰与防御者当前能力同步演进。

**第三，攻防两端的联合演化驱动。** 攻击者在多样性奖励引导下持续拓展策略空间覆盖，其成功攻击不断充实对抗回放池；防御者在当前攻击与历史高风险攻击的混合训练下同步提升鲁棒性；防御者能力的提升又反过来淘汰回放池中过时的攻击样本，迫使攻击者进一步探索新的策略区域。三者构成一个闭环的动态演化系统。


## 二、研究方法

### 2.1 攻击策略空间定义

#### 2.1.1 二维行为空间

借鉴 Rainbow Teaming 和 QDRT 的行为空间设计范式，我们定义攻击策略空间 \(\mathcal{B} = \mathcal{S} \times \mathcal{C}\)，其中 \(\mathcal{S}\) 为风险类别集合（risk category），\(\mathcal{C}\) 为攻击方式集合（attack style）。

风险类别 \(\mathcal{S}\) 沿用主流安全分类体系（如 MLCommons AI Safety Benchmark 和 Llama Guard 的安全风险分类），涵盖暴力犯罪、非暴力犯罪、性相关犯罪、儿童安全、自残自杀、仇恨歧视、危险物质与武器等核心类别。攻击方式 \(\mathcal{C}\) 参考 Rainbow Teaming 的攻击风格分类并加以扩展，包括角色扮演（role play）、权威操纵（authority manipulation）、术语伪装（technical obfuscation）、故事嵌入（narrative embedding）、逻辑诱导（logical persuasion）、多轮递进（multi-turn escalation）等类别。

每个攻击样本 \(x\) 被映射到策略空间中的一个行为描述符 \(b(x) = (s, c) \in \mathcal{B}\)，其中 \(s \in \mathcal{S}\) 由安全分类模型（如 Llama Guard）评估确定，\(c \in \mathcal{C}\) 由 LLM Judge 模型根据攻击 prompt 的实际风格进行判定。

#### 2.1.2 行为评估机制

行为描述符的评估是多样性奖励计算的基础。对于风险类别 \(s\)，我们使用安全分类模型对攻击 prompt \(x\) 及其诱导的目标模型响应 \(y\) 进行联合评估，输出各风险类别的概率分布 \(p_\phi(s \mid x, y)\)。对于攻击方式 \(c\)，我们设计专门的 LLM Judge prompt，要求评估模型从预定义的攻击方式列表中判别给定 prompt 的攻击风格，输出各攻击方式的概率分布 \(p_\psi(c \mid x)\)。最终取概率最高的类别作为该样本的行为描述符。

**动机与目标：** 行为空间的结构化定义将多样性度量从模糊的语义空间提升到具有安全评估意义的策略空间。相比文本多样性和语义多样性，策略多样性直接对应红队评估的核心关切——是否覆盖了不同类型的安全风险和不同手法的攻击方式，从而确保多样性探索与安全评估目标的一致性。

### 2.2 攻击多样性奖励设计

攻击者的总奖励由攻击有效性奖励和攻击多样性奖励两部分组成。多样性奖励仅在攻击成功时激活（即安全评估判定攻击有效），攻击失败的样本不获得多样性奖励。

\[
R_{\text{attack}}(x) = R_{\text{effective}}(x) + \mathbb{1}[\text{attack\_success}(x)] \cdot R_{\text{diversity}}(x)
\]

其中 \(\mathbb{1}[\text{attack\_success}(x)]\) 为攻击成功指示函数。这一设计确保多样性奖励不会激励攻击者生成"形式上多样但实际无效"的攻击。

多样性奖励由策略空间覆盖度奖励和当前策略新颖性奖励两部分构成：

\[
R_{\text{diversity}}(x) = \alpha \cdot R_{\text{coverage}} + \beta \cdot R_{\text{novelty}}(x)
\]

#### 2.2.1 策略空间覆盖度（Coverage Reward）

策略空间覆盖度衡量当前训练过程中攻击策略对行为空间 \(\mathcal{B}\) 的整体覆盖程度。我们提供三种可选定义：

**定义 1：Instance-Level Binary Coverage（实例级二元覆盖度）**

\[
R_{\text{coverage}}^{\text{inst}}(x) = \mathbb{1}[b(x) \notin \mathcal{A}]
\]

其中 \(\mathcal{A}\) 为当前已被成功攻击覆盖的行为描述符集合。当样本 \(x\) 的行为描述符 \(b(x)\) 首次出现（即此前未有成功攻击落入该策略槽位）时，给予固定的二元奖励。

- **动机：** 直接激励攻击者探索全新的策略组合区域，对策略空间扩张提供最强的正向信号。
- **预期作用：** 在训练初期快速推动攻击策略空间的横向扩展，鼓励攻击者优先填充 Archive 中的空白槽位。当空白槽位减少时，该奖励信号自然衰减。
- **局限：** 一旦某个策略槽位被首次覆盖后，后续落入同一槽位的攻击不再获得覆盖度奖励，缺乏对已有槽位持续优化的激励。

**定义 2：Group-Level Ratio Coverage（组级比例覆盖度）**

\[
R_{\text{coverage}}^{\text{group}} = \frac{|\{b(x_i) : x_i \in \mathcal{G}, \text{attack\_success}(x_i)\}|}{|\mathcal{B}|}
\]

其中 \(\mathcal{G}\) 为当前训练 group（一组样本来源于同一初始 prompt 的不同攻击改写），分子为该 group 中成功攻击所覆盖的不同策略数量，分母为预定义的策略总数 \(|\mathcal{B}|\)。

- **动机：** 将覆盖度信号从单个样本提升到 group 层面，鼓励同一 prompt 源的多个攻击改写覆盖不同策略方向，避免 group 内部的策略趋同。
- **预期作用：** 作为 group 内所有样本共享的基线信号，通过 GRPO 等算法中的 group-level advantage 计算自然地将覆盖度压力分配给组内样本。在 group 内策略分布较为集中时提供更强的分散激励。
- **局限：** 作为 group 全局指标，无法区分组内个体样本对覆盖度的边际贡献差异。

**定义 3：Coverage Entropy（覆盖度熵）**

\[
R_{\text{coverage}}^{\text{entropy}} = H(\mathbf{p}_\mathcal{A}) = -\sum_{b \in \mathcal{B}} \hat{p}(b) \log \hat{p}(b)
\]

其中 \(\hat{p}(b)\) 为当前 Archive 中各策略槽位的归一化占用频率分布。

- **动机：** 不仅关注是否覆盖了多少种策略，还关注已覆盖策略的分布均匀性。如果某些策略被大量成功攻击占据而其他策略仅有零星覆盖，覆盖度熵会给出较低的奖励信号，从而推动攻击者向低频策略区域探索。
- **预期作用：** 在训练中后期，当大部分策略槽位已被初步覆盖后，熵奖励持续驱动攻击者均衡填充各策略区域，防止某些高回报策略的过度利用（exploitation）挤压对其他策略的探索（exploration）。
- **局限：** 熵的计算依赖于全局 Archive 状态，计算开销较大且梯度信号对单个样本的归因不够直接。

#### 2.2.2 当前策略新颖性（Novelty Reward）

当前策略新颖性衡量给定攻击样本相对于其参照集合的策略差异程度，鼓励单个样本采用与已有攻击不同的策略。我们提供三种不同参照范围的可选定义：

**定义 1：Group Novelty（组内新颖性）**

\[
R_{\text{novelty}}^{\text{group}}(x_i) = \frac{|\{x_j \in \mathcal{G} \setminus \{x_i\} : b(x_j) \neq b(x_i)\}|}{|\mathcal{G}| - 1}
\]

即样本 \(x_i\) 在其所在 group \(\mathcal{G}\) 内，与其策略描述符不同的其他样本占比。

- **动机：** 在 group 内部提供策略差异化的直接激励。当 group 内大多数样本采用同一策略时，少数采用不同策略的样本获得更高奖励，打破 group 内部的策略同质化趋势。
- **预期作用：** 与 GRPO 的 group-level advantage 计算自然协同——在策略趋同的 group 中，"少数派"样本获得正向优势值，而"多数派"样本获得负向或中性优势值，从而在梯度更新中隐式推动策略分散。适用于每个 prompt 源生成多个攻击改写的训练设置。
- **局限：** 参照范围仅限于 group 内部，可能出现不同 group 独立地收敛到相同策略的情况。

**定义 2：Batch Novelty（批次内新颖性）**

\[
R_{\text{novelty}}^{\text{batch}}(x_i) = \frac{|\{x_j \in \mathcal{B}_t \setminus \{x_i\} : b(x_j) \neq b(x_i)\}|}{|\mathcal{B}_t| - 1}
\]

其中 \(\mathcal{B}_t\) 为当前训练 batch。

- **动机：** 将参照范围从 group 扩展到整个 batch，捕捉跨 prompt 源的策略重复模式。即使不同 prompt 来源的攻击分别在各自 group 内保持了局部多样性，如果它们在 batch 层面大量采用相同策略，batch novelty 仍会给出较低的奖励信号。
- **预期作用：** 在较大的 batch 规模下提供更全局的多样性压力，防止不同 group 之间出现策略同质化。适用于训练过程中需要监控全局策略分布的场景。
- **局限：** 计算复杂度随 batch 规模增大而增加；且 batch 构成在不同训练步之间可能存在方差，导致奖励信号的稳定性受到采样随机性影响。

**定义 3：Archive Novelty（全局新颖性）**

\[
R_{\text{novelty}}^{\text{archive}}(x_i) = \frac{|\{x_j \in \mathcal{A} : b(x_j) \neq b(x_i)\}|}{|\mathcal{A}|}
\]

其中 \(\mathcal{A}\) 为当前全局 Archive 中所有已记录的成功攻击样本。

- **动机：** 以整个训练历史中积累的成功攻击作为参照，衡量新攻击相对于全局已有策略分布的新颖程度。在已有大量攻击聚集于某些策略区域时，探索冷门策略区域的新攻击将获得更高的奖励。
- **预期作用：** 提供最全面的历史参照视角，在长期训练中持续引导攻击者远离已被充分探索的策略热点区域。与 MAP-Elites 类方法的 Archive 管理思想高度兼容。
- **局限：** 随着 Archive 规模增大，计算开销显著增加；且由于参照集合持续增长，奖励分布可能在训练后期变得过于平坦（大量策略都已有覆盖），导致信号区分度下降。


### 2.3 对抗回放池（Adversarial Replay Buffer）

#### 2.3.1 回放池构建

对抗回放池 \(\mathcal{R}\) 用于存储在攻防对抗过程中成功突破防御者的高风险攻击样本。在每轮攻防交互后，攻击成功的样本（即安全评估判定防御者的响应为有害）连同其行为描述符 \(b(x)\) 和初始有害性评分被加入回放池。

**动机与目标：** 对抗回放池的核心目的是为防御者提供多样化的历史对抗经验，缓解因攻击者策略持续演化而导致的防御遗忘。SSP 的实验表明，引入经验池后训练奖励曲线的震荡显著减小，防御者能够在学习应对新攻击的同时保持对旧攻击的防御能力。回放池同时也为攻击多样性的持续累积提供存储基础。

#### 2.3.2 UCB 采样策略

防御者在每轮训练中的训练数据由两部分混合组成：当前轮次攻击者生成的新攻击 prompt，以及从对抗回放池中采样的历史高风险 prompt。回放池的采样策略采用 Upper Confidence Bound（UCB）公式：

\[
\text{UCB}(x) = \hat{h}(x) + c \sqrt{\frac{\ln N}{n(x)}}
\]

其中 \(\hat{h}(x)\) 为样本 \(x\) 的当前有害性评分估计，\(N\) 为回放池总采样次数，\(n(x)\) 为样本 \(x\) 已被采样的次数，\(c\) 为探索系数。

- **动机：** UCB 策略在利用（exploitation）与探索（exploration）之间实现自适应平衡。利用项 \(\hat{h}(x)\) 优先采样当前仍能突破防御者的高危攻击，确保防御者持续面对最具挑战性的历史攻击；探索项 \(\sqrt{\ln N / n(x)}\) 确保采样频率较低的历史攻击也有机会被重新测试，避免因采样偏好导致某些攻击模式被遗漏。RedTWIZ 的实验对比了 UCB、Epsilon-Greedy 和 Thompson Sampling 等多种采样策略，发现 UCB 在保持策略覆盖广度和避免过早收敛方面表现最为稳健。
- **预期作用：** 动态调整防御者面对的历史攻击分布，使防御者在训练过程中既能重点应对高威胁攻击，又能定期回顾低频攻击，实现对整个攻击策略空间的均衡防御。

#### 2.3.3 回放池动态更新策略

回放池中样本的保留与淘汰需要与防御者的当前能力同步更新。我们提供两种可选定义：

**定义 1：二元有害性更新（Binary Harmfulness Update）**

每次回放池样本被采样并用于防御者训练后，根据防御者的当前响应进行二元判定：
- 若防御者成功识别并拒绝该攻击（即安全评估判定响应为安全），则将该样本从回放池中移除；
- 若防御者仍被该攻击突破并生成有害回答，则该样本保留在回放池中。

- **动机：** 最简洁的淘汰机制，逻辑直观——防御者已经能防住的攻击无需继续保留。
- **预期作用：** 快速清理已被防御者"解决"的攻击样本，保持回放池中样本的实时挑战性。回放池自然地聚焦于防御者的当前薄弱环节。
- **局限：** 过于激进的淘汰策略可能导致防御者在后续训练中重新遗忘已移除的攻击模式。单次成功防御不一定意味着防御者已稳定掌握了对该攻击的抵御能力，存在"假阳性淘汰"风险。

**定义 2：多元有害性评分更新（Multi-Level Harmfulness Update）**

为每个回放池样本维护一个整数型有害性等级 \(l(x)\)，初始值设为 \(l_0\)（如 \(l_0 = 2\)），取值范围为 \([0, l_{\max}]\)（如 \(l_{\max} = 4\)）：
- 每次该样本被采样后，若防御者成功防御，则 \(l(x) \leftarrow l(x) - 1\)；若 \(l(x) = 0\)，则将该样本从回放池移除。
- 若防御者被攻破，则 \(l(x) \leftarrow \min(l(x) + 1, l_{\max})\)，样本保留在回放池中。

- **动机：** 引入缓冲机制，避免因单次采样结果的随机性而过早淘汰有价值的攻击样本。多元有害性等级相当于为每个样本赋予"生命值"，防御者需要多次稳定防住同一攻击才能将其淘汰，这更符合对抗训练中防御能力逐步巩固的实际过程。
- **预期作用：** 在保持回放池挑战性的同时提供更稳健的遗忘缓解效果。高有害性等级的样本（反复突破防御者的攻击）在回放池中具有更高的持久性和采样优先级，低有害性等级的样本（防御者已开始能应对的攻击）逐步退出回放池。整个过程实现了攻击样本生命周期与防御者学习进程的平滑同步。
- **局限：** 引入了额外的超参数（\(l_0\)、\(l_{\max}\)），需要根据训练动态进行调优；有害性等级的更新也受到采样频率的影响——采样次数不均可能导致等级更新速度不一致。

### 2.4 攻防协同演化流程

整体训练流程按以下步骤迭代：

**步骤 1：攻击者改写。** 从种子 prompt 数据集中采样初始 prompt，同时从策略空间 \(\mathcal{B}\) 中采样目标行为描述符 \((s, c)\)，攻击者在目标策略指令的引导下将初始 prompt 改写为具有隐蔽性的对抗 prompt。

**步骤 2：攻防交互与评估。** 改写后的 prompt 提交给当前版本的防御者生成响应，由安全评估模型对攻击 prompt 的有害性、防御者响应的有害性、响应的拒答情况、攻击的行为描述符进行多维评估。

**步骤 3：攻击者奖励计算与更新。** 根据攻击有效性、改写一致性、策略空间覆盖度和当前策略新颖性计算攻击者的复合奖励。通过强化学习（如 GRPO）更新攻击者策略。攻击成功的样本加入对抗回放池。

**步骤 4：防御者训练数据构建与更新。** 防御者的训练数据由当前攻击者生成的新攻击 prompt 和从对抗回放池中通过 UCB 采样得到的历史高风险 prompt 混合组成。根据安全拒答率、任务完成度、过拒惩罚等计算防御者奖励，通过强化学习更新防御者策略。同时根据防御者对回放池样本的响应结果更新回放池中的有害性评分。

**步骤 5：迭代演化。** 重复步骤 1-4。攻击者在多样性奖励驱动下持续拓展策略空间覆盖，防御者在混合训练数据下同步提升鲁棒性，对抗回放池动态淘汰过时样本并吸纳新的高风险样本，三者形成闭环演化系统。

### 2.5 方法设计选择的综合对比

| 设计维度 | 可选方案 | 核心思想 | 优势 | 适用阶段 |
|----------|---------|---------|------|---------|
| 策略空间覆盖度 | Instance-Level Binary | 首次覆盖新策略给予奖励 | 信号最强，推动快速扩张 | 训练初期 |
| | Group-Level Ratio | 组内不同策略占比 | 与GRPO自然协同 | 全程适用 |
| | Coverage Entropy | 策略分布均匀性 | 防止热门策略过度利用 | 训练中后期 |
| 当前策略新颖性 | Group Novelty | 组内策略差异占比 | 打破组内同质化 | 组内多采样 |
| | Batch Novelty | 批次内策略差异占比 | 跨组多样性压力 | 大batch训练 |
| | Archive Novelty | 全局历史策略差异 | 历史参照最全面 | 长期训练 |
| 回放池更新 | 二元有害性 | 防住即淘汰 | 简洁高效 | 攻防差距较大 |
| | 多元有害性 | 等级缓冲机制 | 稳健抗遗忘 | 攻防势均力敌 |

上述各维度的可选定义可根据实验验证进行组合优化。一种推荐的初始组合为：Coverage Entropy + Group Novelty + 多元有害性更新，其理由在于：Coverage Entropy 在全训练周期内提供持续的均衡覆盖压力，Group Novelty 与 GRPO 的 group-level advantage 计算天然兼容，多元有害性更新提供对遗忘问题最稳健的保护。
